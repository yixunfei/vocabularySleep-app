# toolbox 模块说明

## 模块概述
`toolbox` 模块聚合睡眠支持、声音工具、专注训练、静心减压、趣味测试和随机决策等子工具。

## 四件套落地状态
- 状态独立: 进行中（子工具各自维护局部状态，仍有部分页面共享 `AppState`）。
- 仓库独立: 部分完成（ambient 路径已仓库化，子工具数据边界仍在推进）。
- 注册驱动: 已落地（入口分组与子模块均由 `ModuleRegistry + module toggle` 驱动）。
- 启停守卫: 已落地（页面访问守卫 + 路由跳转守卫统一接入，禁用后阻断导航）。

## 当前依赖与入口
- 入口: `AppHomeTab.toolbox` -> `ToolboxPage`
- 子模块入口: `toolbox_page_content.dart` 的 `ToolboxEntryData.moduleId`
- 路由守卫: `ui/module/module_access.dart` 的 `pushModuleRoute`

## 首页布局自定义
- 状态模型: `ToolboxLayoutState`，位于 `lib/src/models/settings_dto.dart`。
- 持久化键: `SettingsService.toolboxLayoutKey`，仅保存工具箱首页模块顺序 `order` 和首页隐藏列表 `hidden`。
- 页面入口: `ToolboxPage` 默认展示“我的工具箱”，按 `ToolboxLayoutState` 对 `buildAllToolboxSections()` 中的入口进行排序和过滤。
- 交互能力:
  - 点击“编辑布局”或长按任意工具卡片进入编辑模式。
  - 编辑模式中使用拖拽手柄调整顺序。
  - 点击减号只会从工具箱首页隐藏入口。
  - “恢复隐藏入口”会把入口放回首页。
  - “重置默认”会清空自定义顺序和隐藏列表。
- 边界说明: 首页隐藏不等于禁用模块。全局启停仍由 `ModuleRegistry + ModuleToggleState + ModuleRuntimeGuard` 和模块管理页控制；隐藏入口不会阻断已有路由守卫允许的访问。
- 兼容策略: 渲染和保存前按 `ModuleIds.toolboxModules` 归一化布局状态，过滤未知 ID，并在新增 toolbox 子模块时自动补齐到可见列表末尾。

## 游戏中心
- 入口: `MiniGamesToolPage`
- 页面编排: `lib/src/ui/pages/toolbox_mini_games.dart`
- 俄罗斯轮盘赌文件边界:
  - `toolbox_mini_games_roulette.dart`: 状态机、音效、触觉、计时和主构建入口。
  - `toolbox_mini_games_roulette_view.dart`: 舞台、指标、控制区和设置区 Widget。
  - `toolbox_mini_games_roulette_painters.dart`: 背景、左轮、弹仓和枪口火光 Painter。
- 俄罗斯轮盘赌当前能力:
  - 独立子页 `RouletteGamePage`，移动端最大宽度 600dp，主舞台 + 主操作 + 折叠设置布局。
  - 准备阶段使用弹仓旋转、准备咔哒和拟真机械咔咔声，击发阶段区分撞针释放、空膛步进和命中爆发。
  - 扳机与弹仓音效已调为低沉金属摩擦路线：`revolver_click.wav` 为双段金属咔嚓，`cylinder_spin.wav` 为拖擦 + 棘轮分段 + 落位。
  - 命中时触发爆炸音效、页面级震动、root overlay 血色闪烁、枪口火光和多段触觉反馈。
  - 左轮视觉已补充枪管上肋、准星、退壳杆、弹巢凹槽、侧板螺丝和木质握把纹理；背景调整为暖灰金属台面，避免过黑。
  - 音效为 best-effort 加载；重置、重新旋转和关闭音效时会停止残留效果音，避免声音串场。
  - Android 端使用本地 `audioplayers_android` path override，事件通道回调统一派发到主线程，规避非平台线程消息风险。

  - 按 Human Benchmark 类条目组织 23 个本地趣味测试，覆盖反应、短时记忆、视觉搜索、听觉、视觉辨识、手眼协调、双任务切换、打字、计算和持续注意力。
  - 反应测试升级为多模式实验室：保留经典按住松手，并新增方向滑动与颜色匹配模式；方向输入采用上/左/中/右/下 D-pad，支持中心或主舞台按住后滑向对应方向；方向滑动区域会局部接管手势，避免手机纵向页面滚动抢走上滑/下滑动作；支持轮次、信号节奏、平均/最快/准确率/连击/轨迹反馈。
  - 数字记忆升级为多模式训练：默认数字串复现，新增彩色数字目标、多数字单目标和计算式模式；彩色数字会在展示期和输入期明确提示本轮目标颜色；支持精确毫秒输入、随机停留浮动、随机位数、首位 0、相邻重复、颜色数量、目标组数和计算项数/乘法等细分设置，并在每轮提交后弹出本轮统计报告，由用户确认后再进入下一轮。
  - 词汇记忆升级为三模式训练：词汇模式支持水果、环境、自然、食物、旅行、科技、居家、办公、天气、动物等分领域词库多选，数字模式使用随机数字串并随等级递增长度，空间模式使用 4/8 方向随机箭头序列；支持自定义展示高度、基础重复率、数字起始位数和方向集合，并在结束后弹出完整结果分析报告。
  - 瞄准测试升级为多模式练习场：默认经典点靶，新增降级放大、移动靶和真假干扰模式；降级放大目标会从几乎不可见的点快速显形再持续放大，支持移动放大、移动靶加入真假干扰、真假目标共同移动等可选组合，并可将降级放大包装为虚拟狙击手对决，放大到最大仍未命中时触发震动与红色失败弹窗。完成后弹出完整结果报告，统计模式组合、命中、误点、假目标、超时、狙击失败、准确率、平均命中、最佳连击、评级和训练建议。
  - 黑猩猩测试在经典模式外新增顺序数字模式与颜色顺序模式，支持最大表格大小、本组目标上限、数字/颜色切换速度和颜色目标数量调节；答案显示、下一步提示与一次错误保护均默认关闭，测试完成或失败后可弹出统计分析报告，标注辅助状态、准确率、最佳目标数、用时和训练建议。
  - 打字测试升级为专业训练模块：支持中文、英文、混合、日文和西语语料，按专注、睡眠、技术、短文、词汇和旅行主题抽取内容，并提供短句/标准/长段长度档位；新增经典、冲刺、精准、盲打、符号、纠错、代码和数字模式；实时展示字符级正确/错误/当前输入位置、WPM、净 WPM、CPM、准确率、错误数、回退数、用时、进度和稳定性；完成后生成本页结果报告，包含等级、峰值速度、长停顿、错误结构、错误热区、训练建议、建议练习入口和最近结果。
  - 色觉测试升级为双模式训练：保留经典找不同，并新增混色匹配模式，在较大网格中混入多种相近色块，用户按目标色提示点击完全相同色块；支持红绿色系/蓝黄色系排除、低饱和训练、最大生命（含无限）、初始/最大网格、目标同色块数量和随机目标数设置；提示按钮会高亮目标并计入报告。结束后弹出本页统计报告，展示近轮色差记录、色相分组表现、差异类型表现、弱项判断和训练建议。
  - 视觉记忆改为参考网页节奏：关卡内允许误点 3 次，超限后重开当前关并扣除生命。
  - 斯特鲁普支持一致判断、说出墨色、读出字义和反向规则子模式，可调整颜色数量与题数，并在结束后弹出准确率、反应时和训练建议报告。
  - 运气测试升级为 5 卡牌抽取，支持单抽、十连、二十连、刮刮乐、各品质概率自定义、卡片数量/幸运指数/抽数目标和目标完成报告。多连抽会生成对应数量的真实卡片，手机端使用紧凑网格展示，用户可点击、滑过连续翻开或一键全翻，全部翻开后可平滑继续下一轮；刮刮乐通过手指滑动逐步揭示奖面，并模拟真实即开票的中奖号码、我的号码、奖金、倍数符号、星标自动中奖、票号、包号、校验码和条码票根；史诗/传说抽中时会按队列依次完整显示全屏稀有特效。幸运指数以期望值为 100，按实际总幸运值与概率期望偏离计算，并在报告中给出趣味称号。
  - 时间感知默认单目标节点；连续节点作为独立开关，开启后可设置 2-6 个节点。每轮在最大目标时间内按分钟/秒/毫秒/微秒粒度随机生成目标时刻，开始前显示 3-2-1 倒计时，倒计时结束后才启动秒表；按钮不显示编号，点击后在同一按钮内展示目标时间、实际点击时间和误差。
  - 手眼协调测试从固定往返光标升级为随机延迟出现、随机位置生成、快速移动并消失的目标；支持轮数、显示移动时长/点满才消失、随机运动幅度、速度、目标点大小和需要点击次数设置，并在保留滑动条的同时提供自定义数值输入。
  - 手眼协调测试新增默认关闭的高阶多目标真假干扰：随机等待后可出现一个或多个不同颜色假目标，假目标点击会单独统计；完成后弹出完整结果报告，包含成功、漏掉、点空、假目标、平均/最快反应和逐轮明细。
  - 手眼协调测试支持横屏沉浸全屏训练模式，全屏保留舞台、顶部轻量统计、开始/重置、退出控制和设置面板；全屏内使用独立刷新驱动，目标生成与命中检测避开顶部状态和底部控制安全区，外部设置会继续生效。
  - 新增摇杆手眼协调测试：使用虚拟摇杆移动准星、点击射击命中目标，支持单位时间与目标总数两种方案，可调准星响应位移速率、摇杆位置加速、目标大小，并支持命中后立即刷新或随机延迟刷新。
  - 摇杆手眼协调新增默认关闭的目标移动设置和多目标假目标干扰设置；虚拟摇杆允许拖出摇杆范围并用超出幅度控制准星速率。
  - 摇杆手眼协调支持白底全屏训练模式，舞台尽可能铺满屏幕；射击、状态和会话控制改为半透明浮层，摇杆在手指按下时才显示且不保留方形外框，未开始时也可拖动准星适应操作，顶部小设置入口可用弹窗展开摇杆、目标移动和干扰设置。手机横屏全屏下左侧作为摇杆唤起区、右侧作为射击唤起区，浮层仍随触点重定位；退出后恢复普通页驱动。完成后弹出完整报告，普通页面中射击按钮与开始/重置控制分区，降低误触。
  - 手速测试支持经典连点、目标追击和节奏命中三种玩法，可设置挑战时长，统计命中、尝试、每秒点击、准确率、连击和趣味报告称号。
  - 序列记忆支持图标数量配置，播放重复图标时会强化闪烁；输入阶段新增点击高亮、正确/错误反馈和当前输入进度徽标。
  - 计算能力测试支持轻量/标准/进阶/专家难度，提供混合、加减、乘法、除法、两步题、未知数、指数、阶乘、等差数列和等比数列题型，可按固定题量或限时训练，完成后弹出速度、准确率、错题与训练建议报告。
  - 持续注意力测试支持目标点击、低频目标和 n-back 三类任务，可设置刺激数量、速度节奏、目标比例和 n-back 间隔，并统计命中、漏点、误点、正确抑制和平均反应时；目标背景高亮默认关闭，可在练习时开启，点击后会显示命中/误点/重复点击反馈。
  - 动态视力测试拆分为「字符识别」和「小球数量」双模式；小球数量模式会在舞台内生成随机移动碰撞小球，观察结束后选择数量，答对后逐步增加小球数量与移动速度。
  - 动态视力两个模式均支持折叠设置：字符识别可调整字符集、轮次数、组合长度、选项数量、速度、轨迹、干扰字符和增长曲线；小球数量可调整起始数量、数量上限、速度、观察时长和增长曲线。
  - 动态视力字符识别支持数字、字母、易混淆字符、多字符组合和逗号分割自定义组合，完成后弹出正确率、显示时长、错认记录与训练建议报告；小球数量模式默认同色，可切换多色，并支持观察时长秒数输入。
  - 小球数量模式的数量与速度按等级范围随机抽样，只展示范围不直接展示本轮答案；当前轮次观察或答题中修改设置会弹窗确认，确认后只重置，开始始终由用户点击触发。
  - 测试结果仅在当前页面即时展示，不保存到 AppState、主数据库或学习记录。
  - 当前实现只参考网页条目和规则结构，未复制外站源码或样式。
- 后续扩展预留:
  - 可按独立仓库层追加历史成绩、趋势图、排行榜或多设备同步。
  - 若增加长期成绩记录，应先定义隐私边界、数据保留策略和导出/删除能力。

- `吃什么` 当前额外能力:
  - 午餐和晚餐允许重叠，同一菜品不再被强制切进单一餐段。
  - 高级设置支持“已有材料优先”、做法类型、荤素结构、清真/素食友好和常见忌口过敏等启发式筛选。
  - “已有材料优先”已改为 `exact -> strong -> broad` 三阶段随机池，先取多食材交集，再按高重叠与至少命中 1 项的相关菜谱扩池，避免结果长期只剩 1 道菜。
  - 多食材与自定义忌口均支持 chip 化添加/删除；常见忌口已补齐牛奶、花生、香菜、鱼腥草等入口，自定义项可继续补充蒜、姜、葱等个人雷区；紧凑短语如“番茄鸡蛋豆腐汤”也会拆出多个规范食材 token。

  - “做菜指南”已整理为 `做菜之前 / 基础技能 / 食材匹配与筛选说明 / 参考书目` 等模块，统一承接 `cook` 基础信息、洗菜去残留、烘焙先称量等技能整理，并移除菜谱详情页中的逐条来源说明。
  - 详情页不再为吃什么逐条展示来源说明，统一在指南“参考书目”模块中呈现资料来源；《食物辑要》因竖排古体识别质量不稳，本轮未接入“食疗与禁忌”子页。
  - 页面性能已做专项收口：运行期不再常驻 7000+ 条 full JSON asset，菜谱筛选改为 `DailyChoiceEatCatalog` 预建索引，进入页面只读本地 SQLite 摘要与索引，完整详情按 ID 懒加载，管理页内置菜谱按页构建，远端库首次安装后长期复用本地缓存。

  - 若当前场景精确条目过少，会混入同温度稳妥备选，保证随机结果仍有变化。
  - 自定义编辑器支持勾选 `风格 / 版型 / 样式类型 / 面料与触感 / 亮点` 五组特征；管理页支持按 `风格 / 版型 / 样式类型` 过滤个人衣橱和内置搭配。
  - 指南入口已升级为 8 个模块：基础与风格、版型比例、场合职场、色彩材质、季节天气、鞋履配饰、衣橱练习、扩展边界。

  - 删除内置项只写入隐藏列表，不改种子数据。

  - 吃什么内置菜的“个人调整”会保存在本地 `toolbox_daily_choice_v1.json` 中，优先级为“隐藏 > 个人调整 > 原始内置”；“另存为个人食谱”会生成独立自定义菜，不覆盖原内置条目。
  - 暂不侵入主数据库或 AppState，后续如需同步、备份和导入导出，可迁移到独立仓库层。

## 风险与后续路线
- 风险: 部分历史页面仍可通过独立入口被外部调用，需逐步覆盖统一守卫。
- 风险: 每日抉择第一版使用本地 JSON 存储，若用户清理应用数据，自定义项会一并清除。
- 风险: 吃什么个人食谱集当前仍基于本地 JSON 保存，尚未接入账号同步、备份导入导出或云端冲突合并。
- 风险: 管理页分页只限制 UI 一次性构建数量；若菜谱库扩大到数十万级，管理搜索应迁移到 SQLite 索引查询。
- 风险: 随机助手仅适合低风险、可回退、差异不大的选择，不应替代高风险决策分析或专业意见。
- 风险: 决策助手仅做透明计算和辅助排序，不适合作为医疗、法律、财务等高风险决策依据。
- 风险: 人类测试结果只适合作为趣味反馈，不能作为医学、心理、职业能力或教育评价依据。
- 路线:
  1. 将 remaining toolbox 子页面补齐模块 ID 与访问守卫。
  2. 清理遗留重复页面文件（例如历史 copy 版本）并收敛共享组件。
  3. 为每日抉择补充完整数据同步、导入导出和更细粒度的数学模型。
