# 计划 138: Toolbox 首页编辑态移动端收口

## 基本信息
- **创建日期**: 2026-05-08
- **状态**: 已完成
- **负责人**: Codex

## 目标
继续优化工具箱首页自定义布局体验，重点收口编辑态在移动端的状态可读性、触控热区和恢复隐藏入口的反馈表达。改动仅限展示层与测试，不改变首页隐藏、拖拽排序、恢复和模块全局启停的业务语义。

## 详细步骤
1. 优化编辑态顶部状态面板，将可见/隐藏数量拆成独立可读的状态 chip。
2. 扩大拖拽与移除按钮触控区域，保证移动端编辑操作不低于 48dp 热区。
3. 精修空状态与恢复隐藏入口弹层，使“首页隐藏不等于禁用模块”的边界更清晰。
4. 补充工具箱首页编辑 smoke test，覆盖状态 chip、触控按钮和恢复弹层文案。
5. 更新 changelog，记录本轮 UI 收口与风险边界。

## 风险评估
- **风险 1**: 编辑态 UI 调整误导用户认为模块被全局禁用。
- **缓解措施**: 文案继续明确“只影响首页入口”，不触碰 `ModuleToggleState`。
- **风险 2**: 扩大编辑按钮热区后挤压卡片标题和说明。
- **缓解措施**: 仅调整动作列尺寸，正文仍使用 `Expanded`，并通过 smoke test 验证关键文本可见。
- **风险 3**: 恢复弹层样式改动影响恢复操作。
- **缓解措施**: 保持 `restoreToolboxEntry` 调用路径不变，仅调整容器、图标和文案。
