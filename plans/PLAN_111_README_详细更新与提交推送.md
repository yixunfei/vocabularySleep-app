- **风险 1**: 工作区已有大量未提交改动，直接 `git add .` 会把非本轮业务改动纳入提交。

- **缓解措施**: 以 `pubspec.yaml`、`scripts/`、模块注册表和现有目录为准描述。

- **缓解措施**: 以文档 diff、Git 暂存范围和 Markdown 可读性检查为主，最终说明未运行代码测试。
