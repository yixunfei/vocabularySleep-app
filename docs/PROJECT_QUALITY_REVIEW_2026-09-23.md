# 项目代码质量评估与修复记录

- 日期：2026-09-23

## 检查范围与方法

全量运行 Dart/Flutter 静态分析、Flutter 测试、七语言 catalog 审计和源码规模扫描；对学习/播放入口、依赖装配、睡眠声音、远程缓存与预热、S3 和消除游戏做重点代码检查，并核对近期历史计划。未逐行人工审阅全部约 38.7 万行源码，未测量覆盖率。

开始时工作区已有大量未跟踪词书脚本、词库与报告；本轮未执行、删除或提交这些文件。PATH 中的 rg.exe 无法启动，文本扫描使用 Python/PowerShell 替代。

## 本轮确认并修复

| 问题 | 影响与根因 | 修复与证据 |
| --- | --- | --- |
| 消除游戏跨局回调 | 新开局后，旧交换/消除延迟继续修改新棋盘；90ms 交换延迟在退出时仍有挂起 Timer | 接入既有 generation 字段；每个异步边界核验局次，重开/退出/恢复时取消 Timer 并完成等待 Future。新增交换中重开、连消中重开、退出测试 |
| 睡眠播放器重复释放 | stop 与迟到的 play 完成均释放同一实例 | 弱引用 Expando 保存每个实例的释放 Future，确保一次释放；原失败复现中 disposeCalls 为 2，修复后为 1 |
| 预热取消不完整 | 已取消仍列目录；列目录中取消仍继续下一个前缀；空目录可能错误标为全部完成 | 在请求边界检查取消，结果保留 cancelled |
| 预热门控绕过 | VPN 被当作免费网络，探测失败放行，网络切换后仍继续下载 | 仅识别 Wi-Fi/以太网；未知网络拒绝可选预热；下载间重新检查；VPN、探测异常与切网测试通过 |
| 预热额度无法收敛 | 已缓存对象重复占用 96MiB 额度，重试一直停留在相同前缀；大对象阻塞后续小对象 | 缓存命中不计新增下载字节；跳过超预算对象并保留 capped；两次预热可继续完成余下对象 |
| 缓存完成状态误判 | 零字节文件算作有效缓存；前缀下任意一个文件即可让预热判为无需执行 | 增加逐对象、正长度及期望长度检查；预热下载使用 validator；覆盖空文件和长度不匹配 |
| S3 特殊字符签名 | 表单查询编码将空格变成 +，部分保留字符未转义，Host 签名漏端口 | S3 路径按段单次 RFC3986 编码，查询使用相同组件编码，Host 使用 authority；本地 HTTP 捕获请求，对固定 canonical 文本独立核算签名 |
| S3 XML 文件名损坏 | 连续 replace 把 `&amp;lt;` 二次解码，数字实体未还原 | 改为单遍实体解码；字面实体文本、中文数字实体回归通过 |
| S3 目录缺页 | 只读取第一页，忽略 IsTruncated | 补齐 NextContinuationToken 解析、签名请求和全页聚合；缺失/重复 token 报错，避免静默遗漏与死循环 |
| 既有测试未测试声称的场景 | 音量失败测试未完成初次播放准备，实际等待 15 秒超时后才运行后续步骤 | 明确完成初次准备，使测试真正覆盖旧音量任务与新播放交错 |

消除游戏由一个 1,863 行文件拆为状态/生命周期、异步消除流程、棋盘规则和展示四个文件，最大 570 行；触达的长函数按职责拆解，保留原来的布局、数值、动效时长、玩法与文案 key。此举改善定位，不宣称消除了整个 State 的内部耦合。

## 遗留项处理

- **已补齐的半成品**：消除游戏 generation 取消机制、PLAN_439 的取消/门控/有界重试收敛、PLAN_447 的睡眠声音同实例释放与 S3 编码切片，以及 S3 分页链路。
- **完成状态需以验证为准**：PLAN_443 已实现的资源声明、缓存和 UI 修复纳入本轮全量回归；大范围 UI/accessibility 优化不以这些测试替代真机验收。
- **独立后续设计**：Web 持久化、完整 Web 工具箱/音频/ASR、全量键盘/焦点可访问性、缓存 LRU/TTL、压缩内容解码上限、不同校验器并发访问同一缓存路径的策略、播放器释放超时策略。这些不会伪装为已完成。
- **结构治理优先级**：先拆 AppState 的领域控制器与接口，再按独立业务治理 cognition/bimanual、隐写与密码库的大文件；先增加边界测试，避免只移动文本的机械拆分。
- **可复用方案**：继续使用现有 Flutter test/fake_async 做生命周期测试，使用现有 repository/composition root 作为模块边界；若后续进一步扩展 S3 写入/重试/流式操作，单独评估成熟且持续维护的 S3 SDK，不在本轮引入依赖替换。

## 验证与限制

全量 940 tests 通过（新增 17）；最终静态分析 0 error、4 warning（用户原有未跟踪脚本）、124 info，lib/test 无 error/warning。17 个触达 Dart 文件格式检查通过。详细命令与计数见 [CHANGELOG](../changelogs/CHANGELOG.md) 的 PLAN_450 条目。本轮无新增/退休 i18n key，无数据格式与 Android 签名变更，无版本发布。

- 未运行 Android/Windows 原生发行构建，未连接真机验证后台声音、系统权限、触控与资源消耗。
- S3 新测试使用本地 HTTP 与 fake 分页，不访问远端桶；保留原默认凭据行为，不执行远端写入。
- 预热额度是按对象声明长度限制计划中的新增内容大小，不是含重试、协议开销的硬网络流量限额；取消/切网在当前请求结束后的边界生效，不中断已在传输中的请求。
- Wi-Fi/以太网只是现有网络类型策略，不保证热点或网络实际免费。
- 测试通过不代表每个工具都经过人工交互验收；质量结论不使用未经测量的覆盖率或性能分数。
